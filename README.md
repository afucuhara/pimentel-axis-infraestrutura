# Pimentel Axis Infraestrutura

Site institucional em HTML estático, pronto para hospedagem e para uso dentro de um widget HTML do Elementor.

## Arquivos

- `index.html`: página completa para hospedagem estática.
- `pimentel-axis-widget-elementor.html`: bloco único para colar no widget HTML do Elementor.
- `assets/`: imagens e logotipos usados no projeto.

## Elementor

Abra `pimentel-axis-widget-elementor.html`, copie todo o conteúdo e cole em um widget HTML. Configure a página como Elementor Canvas ou Largura total.
